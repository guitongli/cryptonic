# Trading Floor Sound Samples

Place your `.mp3` sound files in this directory. The app will load them by filename.

## Required files (indoor / trading floor soundscape)

| File | Sound | Triggered by |
|---|---|---|
| `phone_ring.mp3` | Classic desk phone bell | EventSample mappings |
| `keyboard_click.mp3` | Single mechanical keypress | EventSample mappings |
| `keyboard_burst.mp3` | Fast typing burst | EventSample mappings |
| `bell_ding.mp3` | Single chime/ding | EventSample mappings |
| `cash_register.mp3` | Till ring | EventSample mappings |
| `paper_rip.mp3` | Ticker tape tear | EventSample mappings |
| `market_bell.mp3` | Exchange open bell | EventSample mappings |
| `alert_beep.mp3` | Short electronic beep | EventSample mappings |

## Where to download (free, no attribution required)

- https://mixkit.co/free-sound-effects/
- https://pixabay.com/sound-effects/
- https://freesound.org (filter CC0)

## Format

MP3, 44.1 kHz, stereo or mono. Keep files under 1 MB each.

> **Note:** The harp arpeggio (LevelSample) is synthesised in the browser via Web Audio API — no file needed.
